# Calorie Tracker frontend

React and TypeScript with Vite, Oxlint, and Vitest.

The account screen supports registration, login, logout, and saved light/dark
appearance. API requests use the `/api` proxy configured in `vite.config.ts`.

Run `npm run dev`, `npm run lint`, `npm run build`, or `npm run test:coverage`
from this directory. See the [project README](../README.md) for backend,
database, migration, and local startup instructions.
